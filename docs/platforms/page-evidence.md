# 页面证据平台

携程、去哪儿和豆瓣小组当前是固定 URL 页面证据任务，通过 `ctf_resource_crawl.py`
执行并由 `import_ctf_captures.py` 归一化。

- 单页成功只代表该 URL 完成，不能汇报为平台批量目标完成。
- 页面错误、搜索页、中间页和验证码页只保留证据，不生成用户内容记录。
- 粉丝量策略由平台配置声明；页面本身不提供时使用 `ignored`，不得虚构数值。
- 豆瓣小组作者粉丝量使用 people 页面补全；隐私限制保持 NULL 并记录原因。
- `max_image_save` 的现有语义仍是响应样本上限；正文图片全量归属问题继续作为独立遗留项。
